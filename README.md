# push_swap

## GIT Workflow

1. Update Project: git checkout main -> git pull
2. Create Branch (if necessary): git checkout -b <new-branch-name>
3. git push origin <new-branch-name>
4. Push changes: git add, git commit, git push
5. Go to GitHub -> Compare & pull requests -> add Reviewer
6. Reviewer checks code and approve
7. Reviewer can delete branch instantly with "delete branch" (if not necessary anymore -> e.g. utils/ft_atol / main/condition is still necessary...)
8. Delete local Branch (Creator, not Reviewer)
