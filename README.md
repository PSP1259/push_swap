# push_swap

## GIT Workflow

1. Update Project: git checkout main -> git pull
2. Create Branch (if necessary): git checkout -b <new-branch-name>
3. Push changes
4. Go to GitHub -> Compare & pull requests -> add Reviewer
5. Reviewer checks code and approve
6. Reviewer can delete branch instantly with "delete branch" (if not necessary anymore -> e.g. utils/ft_atol / main/condition is still necessary...)
7. Delete local Branch (Creator, not Reviewer)
